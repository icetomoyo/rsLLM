详见 [`v0.1.0.md`](v0.1.0.md)。

## v0.1.1 — AMD iGPU Vulkan 加速

**主线**：让 AMD AI Max+ 上的 DS V4 Flash 从「CPU 慢但能跑」升级为「iGPU 加速可用」。

**Features**：
- **F033** AMD Vulkan compute backend（Radeon 8060S，40 CU RDNA 3.5）
  - 新增 `rsllm-backend-vulkan` crate
  - 用 `ash` Vulkan binding
  - 借鉴 llama.cpp `ggml-vulkan`（MIT）的 compute shader
  - 必交付 kernel：matmul (F16 / Q4_K / Q2_K / IQ2_XXS)、RMSNorm、RoPE-YaRN、SwiGLU、attention（朴素）
  - 不绑 ROCm（ROCm 留给独立 Radeon dGPU，AMD AI Max+ iGPU 走 Vulkan）

**验收**：
- AMD AI Max+ 上 DS V4 Flash decode **≥ 10 tok/s**（v0.1.0 CPU 3 tok/s → v0.1.1 提速 3×+）
- Vulkan kernel 与 CPU NEON reference 数值在 1e-3 误差内

**前置 ADR**：
- ADR-0008：AMD iGPU 路径选 Vulkan compute（不选 ROCm，跨平台 + 兼容 Intel Arc iGPU + NVIDIA dGPU 兜底）

## v0.1.2 — 性能调优 + 数值回归

**主线**：v0.1.0 / v0.1.1 跑通但未调优，本版本对齐 ds4 性能基线 + 全 kernel 数值回归。

**任务**：
- Metal kernel 调优：tile size / threadgroup memory / shared memory 利用
- AVX-512 kernel 调优：cache blocking + prefetch
- Vulkan kernel 调优：workgroup size / subgroup operations
- 全 kernel pairwise 数值对比（CPU NEON / CPU AVX-512 / Metal / Vulkan 四路径）

**验收**：
- Mac M3 Max DS V4 Flash decode **≥ 25 tok/s**（v0.1.0 15 → 25，逼近 ds4 参考线）
- AMD AI Max+ DS V4 Flash decode **≥ 15 tok/s**（v0.1.1 10 → 15）
- 四路径 token 输出在 greedy + seed=0 下首 100 token byte-identical

## v0.1.3 — 磁盘 KV 简化版（cold checkpoint）

**主线**：解决"每次开新会话都重 prefill"的痛点。

**Features**：
- **F022** 磁盘 KV cache 简化版（**仅 cold checkpoint，仿 ds4 KVC v1**）
  - 文件格式：`"KVC"` magic + version + 48 字节 header
  - 文件名：`SHA1(token_ids)` （不是 SHA1(text)，避免 BPE 重新分词不一致）
  - Reason 类型：cold / continued / evict / shutdown（v0.1.3 实现 cold；continued + tool replay 留 v0.2.0 F031）
  - 模型指纹防错（复用 F002 SHA256）
  - LRU 淘汰，`--kv-disk-space-mb` 配置上限

**借鉴**：ds4 `ds4_server.c:4575-5264` KVC 格式与 reason 状态机（MIT）

**验收**：
- 25k token 系统提示 cold 命中时首 token 延迟 **≤ 200ms**
- 跨进程重启缓存仍命中
- 不同模型指纹的 KV 自动拒绝加载

## v0.1.4 — HTTP server 双协议 + tool calling

**主线**：让 rsLLM 能作为 OpenAI / Anthropic / Claude Code 客户端的本地后端。

**Features**：
- **F011** OpenAI Chat Completions API + SSE 流式
- **F012** axum HTTP server（`/healthz`、`/v1/models`、基础限流）
- **F023** Anthropic Messages API + SSE 流式
- **F024** Tool calling
  - DSML 格式（DS V4 原生）↔ OpenAI tools JSON ↔ Anthropic tool_use 三向翻译
  - 借鉴 ds4 `ds4_server.c:4200-4207` tool_memory + rax 索引
- **F018** Prometheus metrics + tracing

**验收**：
- `pytest openai-python` 主流测试用例通过
- Anthropic Python SDK + Claude Code 配置 `ANTHROPIC_BASE_URL` 后能直连 rsLLM
- DSML ↔ OpenAI tool 双向转换 round-trip 一致
- 24h 跑测不崩溃，关键指标暴露

## v0.1.5 — logprob 回归测试体系

**主线**：复刻 ds4 的官方 API 黄金数据回归测试框架，进入"可证明正确"阶段。

**Features**：
- **F034** logprob 回归测试体系
  - `tests/test-vectors/manifest.json` 列出 prompt + 期望
  - `scripts/fetch_official_vectors.py` 从 DeepSeek 官方 API 拉取 `top_logprobs=20`
  - `cargo run --bin rsllm-test -- --logprob-vectors` 跑比对
  - **token bytes 级匹配**（不仅 token id，避免 vocab 漂移）
  - 覆盖 short（事实 / 代码补全 / 推理）+ long（11-12k token 代码审计）两类

**借鉴**：ds4 `tests/test-vectors/`、`tests/ds4_test.c:--logprob-vectors`（MIT）

**验收**：
- 至少 5 个 short prompt + 2 个 long prompt 黄金数据
- CI 每次 push 跑全套 logprob 回归
- 任何 PR 导致 token bytes mismatch 直接 fail

## v0.1.6 — NVIDIA CUDA 后端

**主线**：扩展到 NVIDIA GPU，验证 CAL trait 抽象在第 4 个 backend（CPU / Metal / Vulkan / CUDA）上的可移植性。

**Features**：
- **F009** CUDA backend（cudarc 运行时加载）
  - 借鉴 ggml `ggml-cuda.cu` kernel（MIT）
  - 必交付 kernel 同 Metal/Vulkan 列表
- **F010** Paged KV cache（vLLM 风格，作为 CUDA 路径的备选 KV，与三级 KV 共存）

**前置 ADR**：
- ADR-0002：CUDA 绑定选 cudarc（运行时加载，不静态链接 CUDA toolkit）

**验收**：
- DS V4 Flash 在 4090 24GB 上跑通（量化方案需要按 4090 内存调整，可能用更激进的 IQ2_XXS 比例）
- 或者：DS V4 Flash 量化版在 H100 80GB 上 decode ≥ 30 tok/s

## v0.1.7 — 第二个模型家族

**主线**：v0.1.0-v0.1.6 都聚焦 DS V4 Flash，本版本开始扩展到第二个家族。**新模型 vs 老模型权衡**：选 2026 年活跃的新一代家族（Qwen 3.6 / GLM-5.1 / Kimi K2.6 / Gemma 4 之一）。

**Features**：
- **F013（部分）** 第二个模型家族支持
  - 候选 1：**Qwen 3.6**（tiktoken-style BPE，pre-tokenizer `qwen3`）
  - 候选 2：**GLM-5.1**（智谱新一代）
  - 候选 3：**Kimi K2.6**（Moonshot）
  - 候选 4：**Gemma 4**（Google）
  - 启动前 1 周根据社区热度 + GGUF 可用性最终选定

**通用化代价**：
- 抽象出 `PreTokenizer` trait（v0.1.0 的 JoyAI 是第一个实现）
- 抽象出 `ChatTemplate` trait（v0.1.0 是 DS V4 硬编码）
- 抽象出 `ModelFamily` 元数据机制（绕过 DS V4 固定形状校验）

**验收**：
- 第二家族的代表模型在 Mac M3+ 与 AMD AI Max+ 上跑通
- 与该家族官方 tokenizer 100% 一致（100 句测试集）

## 与 v0.2.0+ 的衔接

v0.1 系列做完后，rsLLM 已经在双硬件上把 ds4 复刻到等价 + 1 个 GPU 扩展（CUDA）+ 3 个模型家族。v0.2.0 开始"超越 ds4"的工作：

- **F019** 异构 CPU+GPU MoE 卸载（`cudaLaunchHostFunc`）
- **F020** AMX/AVX-512 算子统一（v0.1.0 的 DS V4 特化 kernel 通用化）
- **F021** 历史 DS V2/V3 模型支持（v0.1.0 只跑 V4 Flash）
- **F026** 推测解码（MTP / Eagle / Medusa 之一）
- **F031** KVC 完整版（continued checkpoint + tool call replay）
- **F032** Metal 完整版（Flash Attention + MoE matvec 优化）

v0.2.x 处理长尾覆盖（**F016** Continuous Batching、**F017** Prefix cache、**F027** wgpu、**F028** JSON mode、**F029** 多模型控制面、**F030** ROCm dGPU）。
